# IB DP Physics HL 2025–2027 Notes

This repository contains IB DP Physics HL notes, summaries, past paper materials, and review resources for the 2025–2027 syllabus.

## How to download / fetch this repository

### For people who know how to use GitHub:

You can clone this repository by running:

```bash
git clone https://github.com/SupersonicMan12/IB-DP-Programme-Physics-HL-2025-2027-Notes.git
```

After cloning, enter the repository folder:

```bash
cd IB-DP-Programme-Physics-HL-2025-2027-Notes
```

If you already cloned the repository before and want to get the newest version, run:

```bash
git pull
```

This will update your local copy with the latest files from GitHub.

### For people who do not know how to use GitHub:

Open the repository page on GitHub.

Click the green button that says **Code**.

In the menu that opens, click **Download ZIP**.

Wait for the ZIP file to download.

After it finishes downloading, unzip the file.

Open the unzipped folder on your computer.

You can now read the notes directly from the folder.

You do not need to install GitHub or use any commands if you only want to read the files.
